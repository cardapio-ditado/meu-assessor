# Ítalo Moreira 2026 — Landing Page (Prévia)

Prévia de proposta comercial: landing page de campanha para **Ítalo Moreira**,
pré-candidato a Deputado Estadual por São Paulo (Partido Missão), com seção do
candidato a Presidente **Renan Santos**.

## Conteúdo

- `index.html` — página completa, sem dependências externas (abre direto no navegador)

## Seções

1. Herói com partículas douradas e chamada "É a escolha certa"
2. Números do mandato (contadores animados)
3. Fatos do vereador (recordes de produtividade e fiscalização)
4. Propostas para São Paulo
5. Renan Santos — candidato a Presidente (Missão)
6. Clone do perfil do Instagram @italomoreirasp
7. Doação — vaquinha QueroApoiar
8. Formulário "Faça parte" (demonstração)
